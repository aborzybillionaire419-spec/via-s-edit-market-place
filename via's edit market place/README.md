# Via's Edit Market Place

Next.js 14 App Router e-commerce front end.

## Setup

1. Install Node.js (LTS): https://nodejs.org
2. Install dependencies:
   ```
   npm install
   ```
3. Run the dev server:
   ```
   npm run dev
   ```
4. Open http://localhost:3000

## Features

- Product catalog with detail pages
- Shopping cart (client-side context)
- Checkout page
- Responsive Tailwind UI
- Contact via mailto links
